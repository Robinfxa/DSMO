# maidsh-memory · MaiDSH 记忆

让 AI 角色像人一样记得你：会自动记、会淡忘、带着当时的感情，聊到相关的事会自己想起来。可以单独用。

- **自动记**：每轮顺手记下关于你的事（身份、喜好雷点、近况……）和你们之间的经历。关于你本人的事必须有你的原话作证，宁可不记也不记错；你们在扮演 / 故事里发生的也会记，单独标出来。
- **会淡忘，用进废退**：喜好、身份这类大约半年才淡，经历 1–3 周，近况两天；常被想起的越记越牢；淡得想不起来的，你一提关键词又会被唤醒。
- **自然想起**：每轮按你说的话（中文二元组 BM25 + 关键词联想图）想起最多 3 件，加上常驻的「关于对方」几条，注入不超过 400 字，并叮嘱它自然地用、不要逐条复述。
- **细节淡成印象**：零碎的旧事攒够了，压成一段第一人称的「我对 TA 的了解」和一句话印象（偶尔一次额外的小调用）。
- **你说了算**：说「忘掉……」就删；设置页里能看、改、钉住、删除。密码、证件号、银行卡、门牌号永远不记。
- 装了 `maidsh-core` 时，提取并进总控那一次分析，**每轮不多调模型**；装了 `maidsh-bond` 时，还不够亲近时不会主动提私密的回忆；装了 `maidsh-mood` 时，想起带感情的往事会轻轻带动心情，心情好时更容易想起开心的事。
- 数据在 `<DSH_HOME>/storages/maidsh-memory/memory.json`。服务 `companionMemory`；接口 `GET /api/maidsh-memory/list`、`POST /api/maidsh-memory/mutate`（只接本机同源请求）。
- 和 dsh-plugin-memory-share 二选一（同时装会各注入一份）；可以一次性导入它的全局记忆。

配置（都可选）：`provider` + `model`（成对给）、`dataDir`。

设计思路参考 MaiBot（麦麦）的海马体记忆和 A_Memorix，代码从头写，与 MaiBot 官方无关。MIT。
