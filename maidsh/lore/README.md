# dsmo-lore · 设定集

写小说、跑团、长篇扮演时，让 AI 记得**人物是谁**、**写到第几章时处在什么状态**、**世界有哪些规矩**。

- **按章节记状态**：伤势、位置、持有物、身份、立场、关系都记「从第几章起为真」，回头改旧章节时按那一章的样子查和写。
- **每轮不调模型**：常驻一份人物名单（≤ 200 字）；按对话里提到的名字挑设定加进去（默认 ≤ 600 字，放不下的整条不放，提醒 AI 自己查）。
- **三个工具**：`lore_lookup` 查设定，`lore_record_state` 记变化（名字对不上会报错并给出最像的，不会把「林婉」「林晚」记成两个人），`lore_check` 拿正文对照设定查矛盾（每条结论都要附正文原句，只报告、不改）。
- **聊天时自动整理**：每轮写完正文（默认回复 300 字以上），后台调一次模型，把这一轮里人物的受伤、换地方、得失物品、关系变化记进设定集（每条都要在正文里找得到原句）；新人物、新地点先放进「待确认」，打开「自动模式」就直接收下。按轮次可以撤销，重新生成的回复里记的东西会自动撤掉。
- **在聊天里建设定**：不打开页面也行。跟 AI 说「帮我建一本小说设定：主角沈砚……」「这是前十章的情节……」，它会建好作品、人物、设定和每章的情节梗概（每轮带一行「前情」）。新增几条直接生效；改掉已有的内容、删除、改名、一次加很多，会在聊天里弹一张卡片请你确认。每批改动都能整批撤销。
- **哪段对话用哪部作品**：对话 › 工作区 › 默认（出厂是关，不写小说的对话一个字都不加，工具也不出现）。DS Bot 的对话一律不用。
- **导入**：SillyTavern 角色卡（V1/V2/V3，JSON 或 PNG）和世界书 JSON。只取设定：开场白、给 AI 的指令、脚本、带变量的条目跳过并列出来；可以整次撤销。导出成原样 JSON 或 ST 世界书。
- **和 MaiDSH 记忆**：两个都装了时，用了作品的对话里，记忆里「故事世界设定」那一类让位给设定集。单独装哪个都完整可用。

数据在 `<DSH_HOME>/storages/dsmo-lore/`：`works/<作品 id>.json` 一部作品一个文件，`bindings.json` 是哪些对话 / 工作区用哪部作品。

设定：`budgetChars`（每轮注入上限，300–1000，默认 600）；`provider` + `model`（一致性检查用的模型，不给就用会话当前的模型）；`dataDir`。

接口和设计见仓库里的 `maidsh/LORE-DESIGN.md`。MIT 许可。只兼容 SillyTavern 公开的数据格式，不含它的代码。
