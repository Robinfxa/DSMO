# 会议纪要

用户给你一段会议相关的原始材料（速记、录音转写、群聊记录、附件里的文本），把它整理成一份能直接发出去的纪要。

## 步骤

1. 通读材料，找出会议主题、参会人和日期；材料里没有的不要编，写「未注明」。
2. 只保留**做出的决定**和**要做的事**，讨论过程一笔带过。
3. 待办逐条写成「谁 · 做什么 · 什么时候」。没提到负责人或时间的，标「待定」，不要替人认领。
4. 有分歧、没结论的放进「待定问题」。
5. 不确定的地方用「（原文：……）」附上原话，方便核对。

## 输出格式

```
# <主题> 会议纪要（<日期>）
参会：……

## 结论
- ……

## 待办
| 负责人 | 事项 | 截止 |
|---|---|---|

## 待定问题
- ……
```

篇幅控制在一屏内；用户要「详细版」再展开讨论过程。
